## O que é este repositório

Este repositório é o **núcleo operacional** do sistema MILK. Reúne todas as fichas metodológicas dos dispositivos culturais da Associação MILK — propostas activáveis, com formato definido, devolução pública e suporte institucional documentado.

Cada dispositivo é uma unidade de trabalho concreto: oficina, activação territorial, arquivo, ritual, residência, kit ou publicação. Não são conceitos — são instrumentos.

## Governança e Auditoria

A pasta `GOVERNANCA/` contém o **Dossiê Auditável** — o instrumento formal que descreve a arquitectura técnica, semântica, jurídica, financeira, política e económica do sistema MILK.

Este documento é utilizável perante:
- Financiadores públicos (DGArtes, Portugal 2030, Creative Europe, Horizon Europe)
- Auditores jurídicos e fiscais
- Parceiros académicos (CIDOC-CRM, Dublin Core, FAIR)
- Plataformas europeias de património (Europeana, OpenAIRE)
- Instituições públicas municipais e nacionais

→ Ver: [`GOVERNANCA/Dossie-Auditavel-Arquitectura-MILK-Regime-Integracao-Atlas.md`](GOVERNANCA/Dossie-Auditavel-Arquitectura-MILK-Regime-Integracao-Atlas.md)

## Padrões e Interoperabilidade

Todos os dispositivos seguem:

- **CIDOC-CRM** (ISO 21127:2014) para estrutura ontológica
- **Dublin Core** para metadados mínimos
- **FAIR Principles** para gestão de dados
- **GeoJSON / WGS84** para georreferenciação
- **SKOS** para vocabulários controlados
- **Europeana Data Model** para compatibilidade europeia
